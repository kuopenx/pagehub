# Pagehub v0.6.1

[English](https://github.com/kuopenx/pagehub/blob/v0.6.1/docs/releases/v0.6.1.md) · [简体中文](https://github.com/kuopenx/pagehub/blob/v0.6.1/docs/releases/v0.6.1.zh-CN.md)

修复从具体页面使用浏览器返回键回到 Dashboard 时丢失滚动位置的问题，包括浏览器从前进/后退缓存恢复的情况。每条 Dashboard 浏览历史独立保存滚动位置；搜索和排序更新网址时保留这项状态，浏览器原生恢复机制继续作为兜底。刷新页面仍回到顶部，网址锚点仍正常生效。

## 安装或升级

本版本仅发布源码，不上传二进制或安装包。

```sh
brew update
brew upgrade pagehub
pagehub setup
pagehub doctor
```

macOS 或 Linux 使用 Go 1.26.0+：

```sh
go install github.com/kuopenx/pagehub/cmd/pagehub@v0.6.1
pagehub setup
pagehub doctor
```

保留现有页面、URL、修订号、模型归属、配置和令牌。新安装可使用 `brew install kuopenx/tap/pagehub`。

## 验证

本机 race 测试、vet、构建及隔离的 macOS 真实 CLI/MCP 验收通过。JavaScript 检查覆盖缓存与非缓存的前进/返回、刷新、直接访问、锚点、无效位置及历史状态写入失败时的兜底。用户已在本机安装的修复版中确认滚动恢复效果。macOS/Linux CI 与源码发布工作流在发布前验证源码。
