# Pagehub v0.5.3

[English](https://github.com/kuopenx/pagehub/blob/v0.5.3/docs/releases/v0.5.3.md) · [简体中文](https://github.com/kuopenx/pagehub/blob/v0.5.3/docs/releases/v0.5.3.zh-CN.md)

Dashboard 换上新外观。以暖中性色的层次表面取代边框：卡片是带柔和阴影的浮起面板，圆角更大；搜索框是醒目的大号胶囊，排序、刷新、提示、变化通知和二维码对话框使用统一的胶囊控件。浅色与深色外观均跟随系统设置。复制链接和扫码改为紧凑的图标按钮，使用鼠标时悬停卡片才出现，触屏设备上始终显示；无障碍标签保持不变。每个页面仍以小圆点保留各自的颜色。

刷新 Dashboard 时现在回到列表顶部，用浏览器返回键则回到列表原来的位置。

Dashboard 仍是单个内嵌、自包含的 HTML 文件，不下载任何字体、脚本或样式表。页面、MCP 工具、schema、存储、修订号、归属记录和令牌均未改变。

## 安装或升级

本版本仅发布源码，不上传二进制或安装包。

使用 Homebrew：

```sh
brew update
brew upgrade pagehub
pagehub setup
pagehub doctor
```

macOS 或 Linux 使用 Go 1.26.0+：

```sh
go install github.com/kuopenx/pagehub/cmd/pagehub@v0.5.3
pagehub setup
pagehub doctor
```

升级托管服务后刷新 Dashboard。新安装可使用 `brew install kuopenx/tap/pagehub`。

## 验证

本机完整 race 测试、vet、构建和真实 CLI/MCP 验收通过。本机检查了浅色、深色和手机宽度的 Dashboard 截图；二维码对话框的布局以程序方式检查，悬停状态未做截图验收。浏览器检查确认刷新回到顶部、返回键恢复列表位置。macOS/Linux CI 和源码发布工作流在发布前验证标签源码。
