# Pagehub v0.5.1

[English](https://github.com/kuopenx/pagehub/blob/v0.5.1/docs/releases/v0.5.1.md) · [简体中文](https://github.com/kuopenx/pagehub/blob/v0.5.1/docs/releases/v0.5.1.zh-CN.md)

Dashboard cards now place model attribution below the page ID. Created by and Updated by appear on separate lines in smaller, muted text without bold emphasis. Each missing attribution field is hidden; pages with no attribution show no placeholder or empty attribution block.

MCP required attribution arguments and stored metadata remain unchanged. Existing pages, tokens, URLs, and revisions remain compatible.

## Install or upgrade

This is a source-only release without uploaded binaries or installers.

With Homebrew:

```sh
brew update
brew upgrade pagehub
pagehub setup
pagehub doctor
```

With Go 1.26.0+ on macOS or Linux:

```sh
go install github.com/kuopenx/pagehub/cmd/pagehub@v0.5.1
pagehub setup
pagehub doctor
```

Refresh the Dashboard after upgrading the managed service. New installations can use `brew install kuopenx/tap/pagehub`.

## Validation

Dashboard rendering tests check placement below the ID, escaped attribution, missing fields, and updater-only legacy pages. Full race tests, vet, build, and real CLI/MCP acceptance validate the release. CI runs on macOS and Linux before publication. Browser screenshot acceptance is unavailable in the local environment.
