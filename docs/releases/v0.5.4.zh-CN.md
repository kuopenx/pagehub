# Pagehub v0.5.4

[English](https://github.com/kuopenx/pagehub/blob/v0.5.4/docs/releases/v0.5.4.md) · [简体中文](https://github.com/kuopenx/pagehub/blob/v0.5.4/docs/releases/v0.5.4.zh-CN.md)

点击或轻触 Dashboard 的空白处时，导航栏下方不再出现蓝色线条。主列表区域可获得焦点，以便跳转链接把键盘焦点移到列表；现在隐藏了它的浏览器焦点轮廓。按钮、链接和搜索框仍保留可见的焦点环。

页面、MCP 工具、schema、存储、修订号、归属记录和令牌均未改变。

## 安装或升级

本版本仅发布源码，不上传二进制或安装包。

使用 Homebrew：

```sh
brew update
brew upgrade pagehub
pagehub setup
pagehub doctor
```

macOS 或 Linux 使用 Go 1.26.0+：

```sh
go install github.com/kuopenx/pagehub/cmd/pagehub@v0.5.4
pagehub setup
pagehub doctor
```

升级托管服务后刷新 Dashboard。新安装可使用 `brew install kuopenx/tap/pagehub`。

## 验证

本机完整 race 测试、vet、构建和真实 CLI/MCP 验收通过。浏览器检查确认主区域获得焦点时没有轮廓。macOS/Linux CI 和源码发布工作流在发布前验证标签源码。
