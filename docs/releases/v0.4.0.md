# Pagehub v0.4.0

[English](https://github.com/kuopenx/pagehub/blob/v0.4.0/docs/releases/v0.4.0.md) · [简体中文](https://github.com/kuopenx/pagehub/blob/v0.4.0/docs/releases/v0.4.0.zh-CN.md)

Pagehub now supports background services on both macOS and Linux. `pagehub setup` selects a user LaunchAgent on macOS or a user systemd unit on Linux, starts the service, enables login autostart, and waits for a health response from the managed process.

## Changes

- Linux supports repeatable setup, service status/start/stop/restart, doctor, service-name and port migration, and uninstall. Service status reports whether login autostart is enabled.
- Failed Linux upgrades restore the previous executable, settings, unit, running state, and autostart state. Uninstall disables the owned service and keeps pages, settings, token, and client registrations.
- Linux startup handles paths containing spaces, quotes, percent signs, and dollar signs. Explicit starts and rollback recover from systemd's failed state and startup rate limit.
- Foreign systemd units and drop-ins are rejected. Pagehub supports only macOS and Linux; foreground serving remains available on either platform.
- Linux CI and source-release acceptance now exercise real user systemd services and all six MCP tools.

Linux background management requires systemd 240+ and a working user session/bus. To start before login and remain running after logout, explicitly enable lingering with `loginctl enable-linger "$USER"` if needed. Pagehub does not change linger settings.

Pages and the Dashboard continue to listen on IPv4 `0.0.0.0:8765` by default. MCP management remains restricted to authenticated loopback requests. Existing pages, UUIDs, URLs, creation times, tokens, and revisions remain compatible.

## Install or upgrade

This is a **source-only release** with no uploaded binaries or installers. GitHub provides source ZIP and tar.gz archives automatically.

On macOS with Homebrew:

```sh
brew install kuopenx/tap/pagehub
# Existing installations: brew upgrade pagehub
pagehub setup
pagehub doctor
```

With Go 1.26.0+ on macOS or Linux:

```sh
go install github.com/kuopenx/pagehub/cmd/pagehub@v0.4.0
pagehub setup
pagehub doctor
```

Connect a client with `pagehub connect codex` or `pagehub connect claude`. Restart foreground instances to use the new executable.

## Validation

The implementation passed full race tests, `go vet`, builds, and real CLI/MCP acceptance on macOS and Linux ARM64. Additional Linux VM checks covered cold-boot autostart with an already enabled linger setting, background operation, daemon reload, process recovery, successful upgrade and failed-upgrade rollback, data persistence, foreign-unit protection, repeated uninstall, and direct host-to-VM page access. LAN MCP requests were rejected as expected. CI also validates Linux and macOS before publication.
