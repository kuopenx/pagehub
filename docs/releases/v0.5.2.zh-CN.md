# Pagehub v0.5.2

[English](https://github.com/kuopenx/pagehub/blob/v0.5.2/docs/releases/v0.5.2.md) · [简体中文](https://github.com/kuopenx/pagehub/blob/v0.5.2/docs/releases/v0.5.2.zh-CN.md)

新页面只记录创建者。第 1 版的元数据和 MCP 返回值省略 `updated_by`，Dashboard 只显示 Created by。首次成功更新或 patch 产生第 2 版时才记录更新者，后续写入保留最近更新者。失败不产生更新者、不增加修订号。

旧版本会在创建时错误地初始化更新者。现在加载第 1 版记录时忽略该字段，不改写现有文件；Dashboard 和 MCP 返回值也会省略更新者，直到实际更新。创建者、页面 ID、URL、内容、修订号和令牌继续兼容。

MCP 创建仍必须填写 `created_by`，更新和 patch 仍必须填写 `updated_by`。客户端须兼容页面返回值中缺少 `updated_by` 的情况。升级后刷新工具，加载新的输出 schema 和说明。

## 安装或升级

本版本仅发布源码，不上传二进制或安装包。

使用 Homebrew：

```sh
brew update
brew upgrade pagehub
pagehub setup
pagehub doctor
```

macOS 或 Linux 使用 Go 1.26.0+：

```sh
go install github.com/kuopenx/pagehub/cmd/pagehub@v0.5.2
pagehub setup
pagehub doctor
```

升级托管服务后刷新 Dashboard。新安装可使用 `brew install kuopenx/tap/pagehub`。

## 验证

本机完整 race 测试、vet、构建和真实 CLI/MCP 验收通过。回归验证涵盖创建时仅记录创建者、元数据和返回值省略更新者、首次更新与 patch、失败原子性、旧首版记录兼容及 Dashboard 展示。macOS/Linux CI 和源码发布工作流在发布前验证标签源码。本机未做截图验收。
