# Pagehub v0.4.1

[English](https://github.com/kuopenx/pagehub/blob/v0.4.1/docs/releases/v0.4.1.md) · [简体中文](https://github.com/kuopenx/pagehub/blob/v0.4.1/docs/releases/v0.4.1.zh-CN.md)

修复 Fedora 等发行版带有全局 systemd 用户服务 drop-in 时无法 setup 的问题。0.4.0 会错误地将所有 drop-in 视为其他安装的配置并拒绝 setup。

现在允许直接位于 `/usr/lib/systemd/user/service.d/` 或 `/lib/systemd/user/service.d/` 下的发行版全局默认配置，并保留这些文件。其他安装的 unit、服务专属 drop-in 和管理员或用户的 override 仍会被拒绝并受到保护。

## 安装或升级

本版本仅发布源码，不上传二进制或安装包。

macOS 使用 Homebrew：

```sh
brew update
brew upgrade pagehub
pagehub setup
pagehub doctor
```

macOS 或 Linux 使用 Go 1.26.0+：

```sh
go install github.com/kuopenx/pagehub/cmd/pagehub@v0.4.1
pagehub setup
pagehub doctor
```

无需删除 Fedora 的全局配置来绕过旧版错误。若升级后仍拒绝 drop-in，请检查其路径：服务专属和本地 override 会继续受到保护。

## 验证

完整 race 测试、`go vet` 和 macOS 真实 CLI/MCP 验收通过。在 Lima 中加入临时的 Fedora 式发行版全局 drop-in 后，真实 Linux systemd 验收通过，覆盖重复 setup、生命周期命令、迁移、卸载和全部六个 MCP 工具；全局配置保持不变。回归测试确认仍会拒绝服务专属、管理员或用户、混合及格式异常的 drop-in 路径。本次在 Ubuntu 上复现 Fedora 的配置模式，并非完整 Fedora 44 安装测试。
