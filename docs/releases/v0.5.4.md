# Pagehub v0.5.4

[English](https://github.com/kuopenx/pagehub/blob/v0.5.4/docs/releases/v0.5.4.md) · [简体中文](https://github.com/kuopenx/pagehub/blob/v0.5.4/docs/releases/v0.5.4.zh-CN.md)

Clicking or tapping empty space on the Dashboard no longer draws a blue line under the navigation bar. The main list region is focusable so the skip link can move keyboard focus to it; its browser focus outline is now hidden. Buttons, links, and the search field keep their visible focus rings.

Pages, MCP tools, schemas, storage, revisions, attribution, and tokens are unchanged.

## Install or upgrade

This is a source-only release without uploaded binaries or installers.

With Homebrew:

```sh
brew update
brew upgrade pagehub
pagehub setup
pagehub doctor
```

With Go 1.26.0+ on macOS or Linux:

```sh
go install github.com/kuopenx/pagehub/cmd/pagehub@v0.5.4
pagehub setup
pagehub doctor
```

Refresh the Dashboard after upgrading the managed service. New installations can use `brew install kuopenx/tap/pagehub`.

## Validation

Full race tests, vet, build, and real CLI/MCP acceptance passed locally. A browser check confirmed the focused main region has no outline. macOS/Linux CI and the source-release workflow validate the tagged source before publication.
