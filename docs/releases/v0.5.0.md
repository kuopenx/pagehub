# Pagehub v0.5.0

[English](https://github.com/kuopenx/pagehub/blob/v0.5.0/docs/releases/v0.5.0.md) · [简体中文](https://github.com/kuopenx/pagehub/blob/v0.5.0/docs/releases/v0.5.0.zh-CN.md)

Every page now records its creator and latest updater as caller-reported model name and reasoning effort. MCP responses and Dashboard cards show `created_by` and `updated_by`.

## Required MCP arguments

This release changes the write interface: `create_page` requires `created_by`; `update_page` and `patch_page` require `updated_by`. Existing callers must add these arguments. Reconnect or refresh tools to load the new schemas and agent instructions.

Use a single-line `model-name / reasoning-effort` label, such as `model-name / high`, based on the agent's actual current runtime. If a component is unavailable, use `unknown` for that component instead of guessing. These labels are self-reported; Pagehub cannot verify the running model. Missing, blank, malformed, control-character, and non-string values are rejected.

Create initializes both fields to the creator. Successful updates and patches preserve the creator and record the latest updater atomically with content and revision. Failed writes change neither content nor attribution. Attribution is persisted in `page.json` and safely escaped on the Dashboard.

Existing pages remain compatible without migration. Missing legacy attribution returns empty strings and displays “未记录” (not recorded). Updating an old page records its updater while leaving the original creator unknown. Page IDs, URLs, creation times, revisions, and the management token are preserved during service upgrade.

## Install or upgrade

This is a source-only release with no uploaded binaries or installers.

With Homebrew:

```sh
brew update
brew install kuopenx/tap/pagehub
# Existing installations: brew upgrade pagehub
pagehub setup
pagehub doctor
```

With Go 1.26.0+ on macOS or Linux:

```sh
go install github.com/kuopenx/pagehub/cmd/pagehub@v0.5.0
pagehub setup
pagehub doctor
```

`setup` upgrades the managed background executable; restart foreground instances separately. Refresh MCP tools in every connected client after upgrading.

## Validation

Full race tests, `go vet`, and real CLI/MCP acceptance passed on macOS and Linux in Lima. Checks cover required attribution, immutable creators, latest updaters, atomic failures, concurrent revision conflicts, persistence, legacy metadata, and Dashboard escaping. Dashboard rendering was tested; screenshot acceptance was unavailable in the local browser environment. CI validates both platforms before publication.
