# Pagehub v0.5.1

[English](https://github.com/kuopenx/pagehub/blob/v0.5.1/docs/releases/v0.5.1.md) · [简体中文](https://github.com/kuopenx/pagehub/blob/v0.5.1/docs/releases/v0.5.1.zh-CN.md)

Dashboard 卡片将模型归属移到页面 ID 下方。Created by 和 Updated by 分两行展示，字体更小、颜色更淡，不再加粗。未记录的字段单独隐藏；两项均未记录时不显示占位文字或空的归属区块。

MCP 必填归属参数和存储元数据保持不变。现有页面、令牌、URL 和修订号继续兼容。

## 安装或升级

本版本仅发布源码，不上传二进制或安装包。

使用 Homebrew：

```sh
brew update
brew upgrade pagehub
pagehub setup
pagehub doctor
```

macOS 或 Linux 使用 Go 1.26.0+：

```sh
go install github.com/kuopenx/pagehub/cmd/pagehub@v0.5.1
pagehub setup
pagehub doctor
```

升级托管服务后刷新 Dashboard。新安装可使用 `brew install kuopenx/tap/pagehub`。

## 验证

Dashboard 渲染测试验证 ID 下方的位置、归属转义、未记录字段隐藏及仅有更新者的旧页面。完整 race 测试、vet、构建和真实 CLI/MCP 验收验证该版本；CI 在发布前运行 macOS 和 Linux 检查。本机浏览器环境不可用，未做截图验收。
