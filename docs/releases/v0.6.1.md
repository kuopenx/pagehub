# Pagehub v0.6.1

[English](https://github.com/kuopenx/pagehub/blob/v0.6.1/docs/releases/v0.6.1.md) · [简体中文](https://github.com/kuopenx/pagehub/blob/v0.6.1/docs/releases/v0.6.1.zh-CN.md)

Fix dashboard scroll restoration when returning from a page with the browser Back button, including restoration from the browser back/forward cache. Each dashboard history entry saves its own scroll position. Search and sort URL updates preserve that state; native browser restoration remains enabled as a fallback. Reloading still starts at the top, and URL anchors remain respected.

## Install or upgrade

This is a source-only release with no uploaded binaries or installers.

```sh
brew update
brew upgrade pagehub
pagehub setup
pagehub doctor
```

Or with Go 1.26.0+ on macOS or Linux:

```sh
go install github.com/kuopenx/pagehub/cmd/pagehub@v0.6.1
pagehub setup
pagehub doctor
```

Existing pages, URLs, revisions, model attribution, settings, and tokens are preserved. New Homebrew installations can use `brew install kuopenx/tap/pagehub`.

## Validation

Local race tests, vet, build, and real isolated macOS CLI/MCP acceptance passed. JavaScript checks cover cached and uncached back/forward navigation, reloads, direct navigation, anchors, invalid saved positions, and history-write failure fallback. The user confirmed the scroll fix in the installed local build. macOS/Linux CI and the source-release workflow validate the tagged source before publication.
