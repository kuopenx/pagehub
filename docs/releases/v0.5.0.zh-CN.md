# Pagehub v0.5.0

[English](https://github.com/kuopenx/pagehub/blob/v0.5.0/docs/releases/v0.5.0.md) · [简体中文](https://github.com/kuopenx/pagehub/blob/v0.5.0/docs/releases/v0.5.0.zh-CN.md)

每个页面现在记录创建者和最近更新者，由调用者填写当前模型名称及推理强度。MCP 返回值和 Dashboard 卡片展示 `created_by`、`updated_by`。

## MCP 新增必填参数

本版本改变写入接口：`create_page` 必须填写 `created_by`；`update_page` 和 `patch_page` 必须填写 `updated_by`。现有调用方须补充这些参数。重新连接或刷新工具，以加载新的 schema 和 agent 说明。

根据 agent 实际运行信息填写单行 `model-name / reasoning-effort` 标签，例如 `model-name / high`。无法确定的部分使用 `unknown`，不要猜测。标签由调用者自报，Pagehub 无法核验实际模型。缺失、空白、格式错误、含控制字符及非字符串的值均会被拒绝。

创建时两项初始化为创建者。更新和 patch 成功时保留创建者，并将最近更新者与内容、修订号一起原子保存；失败不会改变内容或归属。归属保存在 `page.json` 中，Dashboard 展示时安全转义。

现有页面无需迁移，继续兼容。旧页面缺少归属时返回空字符串并显示“未记录”。后续更新记录更新者，原创建者仍保持未知。服务升级保留页面 ID、URL、创建时间、修订号和管理令牌。

## 安装或升级

本版本仅发布源码，不上传二进制或安装包。

使用 Homebrew：

```sh
brew update
brew install kuopenx/tap/pagehub
# 已安装时：brew upgrade pagehub
pagehub setup
pagehub doctor
```

macOS 或 Linux 使用 Go 1.26.0+：

```sh
go install github.com/kuopenx/pagehub/cmd/pagehub@v0.5.0
pagehub setup
pagehub doctor
```

`setup` 升级托管后台可执行文件；前台实例需单独重启。升级后请在所有连接的 MCP 客户端中刷新工具。

## 验证

完整 race 测试、`go vet`、macOS 和 Lima Linux 真实 CLI/MCP 验收通过。验证涵盖必填归属、创建者不可修改、最近更新者、失败原子性、并发修订冲突、持久化、旧元数据兼容及 Dashboard 转义。Dashboard 已做渲染测试；本机浏览器环境不可用，未做截图验收。CI 在发布前验证两个平台。
