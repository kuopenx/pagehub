# Pagehub v0.5.3

[English](https://github.com/kuopenx/pagehub/blob/v0.5.3/docs/releases/v0.5.3.md) · [简体中文](https://github.com/kuopenx/pagehub/blob/v0.5.3/docs/releases/v0.5.3.zh-CN.md)

The Dashboard has a new look. Warm neutral surfaces replace bordered boxes: cards are raised sheets with soft shadows and larger radii, the search field is a large pill, and sorting, refresh, toasts, the change prompt, and the QR dialog use matching pill controls. Light and dark appearances both follow the system setting. Copy-link and QR actions become compact icon buttons that appear on hover with a pointer and stay visible on touch screens; their accessible labels are unchanged. Each page keeps its own color as a small dot.

Reloading the Dashboard now starts at the top of the list, while the browser back button returns to the previous list position.

The Dashboard remains one embedded, self-contained HTML file with no downloaded fonts, scripts, or stylesheets. Pages, MCP tools, schemas, storage, revisions, attribution, and tokens are unchanged.

## Install or upgrade

This is a source-only release without uploaded binaries or installers.

With Homebrew:

```sh
brew update
brew upgrade pagehub
pagehub setup
pagehub doctor
```

With Go 1.26.0+ on macOS or Linux:

```sh
go install github.com/kuopenx/pagehub/cmd/pagehub@v0.5.3
pagehub setup
pagehub doctor
```

Refresh the Dashboard after upgrading the managed service. New installations can use `brew install kuopenx/tap/pagehub`.

## Validation

Full race tests, vet, build, and real CLI/MCP acceptance passed locally. Light, dark, and phone-width Dashboard screenshots were reviewed locally; the QR dialog's layout was checked programmatically, and hover states were not screenshot-tested. Browser checks confirmed that reload starts at the top and back navigation restores the list position. macOS/Linux CI and the source-release workflow validate the tagged source before publication.
