# Pagehub v0.6.0

[English](https://github.com/kuopenx/pagehub/blob/v0.6.0/docs/releases/v0.6.0.md) · [简体中文](https://github.com/kuopenx/pagehub/blob/v0.6.0/docs/releases/v0.6.0.zh-CN.md)

MCP clients on other devices can now connect to `http://<server-LAN-IPv4>:8765/_mcp` with an active Bearer token. MCP checks tokens without restricting source IP, Host, or Origin. Local client registration continues to use loopback. Browser CORS headers are unchanged.

## Independent device tokens

Run token maintenance commands on the Pagehub host:

```sh
pagehub token generate --name laptop
pagehub token generate --name phone
pagehub token list
pagehub token show --name phone
pagehub token status --name phone
pagehub token rotate --name phone
pagehub token revoke --name phone
```

Only `generate`, `show`, and `rotate` print the selected secret for copying. Listing shows names and states without secrets. Commands support `--data-dir` and `--json`, work while the service is stopped, and report output failures with a nonzero exit code without including credentials in the diagnostic.

The original credential stays in `<data-dir>/token` as `default`; commands without `--name` manage it. Named credentials are stored privately in `tokens.json`. Generating an active name reuses its token. Rotation or revocation invalidates only that token on subsequent requests, without restarting the service; already authorized operations may finish. Revocation survives setup and restarts. Other device tokens keep working, including when the default is revoked. All tokens have the same six-tool permissions and share the same pages.

Pages, URLs, revisions, and model attribution are preserved. Pages and the Dashboard remain accessible without credentials. Use trusted content on a trusted LAN; HTTP does not encrypt tokens. `connect` and `doctor` still use the default token, so `doctor` reports a problem if it is deliberately revoked even when named device tokens work.

## Install or upgrade

This is a source-only release without uploaded binaries or installers.

With Homebrew:

```sh
brew update
brew upgrade pagehub
pagehub setup
pagehub doctor
```

With Go 1.26.0+ on macOS or Linux:

```sh
go install github.com/kuopenx/pagehub/cmd/pagehub@v0.6.0
pagehub setup
pagehub doctor
```

Run `setup` after upgrading to replace the managed background executable. Existing pages, settings, and the original token are retained. New installations can use `brew install kuopenx/tap/pagehub`.

## Validation

Full race tests, vet, build, and real CLI/MCP acceptance passed locally on macOS. Real Linux systemd acceptance also passed in Lima. Checks cover independent device tokens, live invalidation, repeated commands, revocation across setup/restart, unchanged existing page content and revisions, and failed output handling. macOS/Linux CI and the source-release workflow validate the source before publication.
